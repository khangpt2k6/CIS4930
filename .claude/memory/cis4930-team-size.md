For CIS 4930 (ML for Computer Systems, USF, Fall 2026, Santosh Pandey), the final project team size is 3-4 students. The Simple Syllabus PDF on the user's desktop says "Teams of 2-3 students" but that is outdated; the syllabus itself is marked tentative.

**Why:** Scoping advice for the final project (40% per the user, see [[cis4930-final-project]]) depends on headcount, and the PDF is the only written source so it is easy to trust it wrongly.

**How to apply:** Plan project scope, workstream splits, and proposal drafts for 4 people. Treat other "tentative" details in that PDF (grade weights, schedule) as possibly revised too, and confirm with the user rather than quoting the PDF as settled. See [[cis4930-project-shortlist]].
