Write spoken presentation scripts as "- " hyphen bullet talking points per slide, in a formal, professional academic register: complete, connected sentences, no contractions, no casual phrasing ("you might wonder", "just isn't practical", "quite a bit", "Wrong."). "I" is fine for structure ("In this part, I will present"). Add pronunciation hints in italic parentheses at first use of hard terms, names and numbers (the user is a non-native English speaker presenting in English). Same register for slide text such as survey answers ("Incorrect." not "Wrong.").

**Why:** the user rejected two drafts in a row: dense paragraphs with punchy short sentences ("too tense", choppy, "câu chữ cụt ngủn"), then a conversational version ("not professional or formal at all").

**How to apply:** for any talk script, 2 to 5 bullets per slide, measured academic tone like a conference talk, calm rather than dramatic, plus a pronunciation key. This overrides the "short sentences" default in the global report-style rules for scripts. Related: [[research-review-tone]]
